#   Termux:  pip install pypdf          # pure-Python text extraction
#   Desktop: pip install pymupdf        # most robust (text + render); does NOT
#                                       # build on Termux/aarch64 — skip it there
#
# Scanned/encrypted PDF OCR fallback — a renderer + a vision model:
#   Termux:  pkg install poppler && pip install pdf2image   # installable on-device
#   Desktop: pip install pymupdf
#   plus a vision model: ollama pull moondream
#
# Browser tool (Playwright) — heavy on Termux; typically run on the LAN box:
#   pip install playwright && playwright install chromium
# playwright>=1.40
#
# Vision (analyze_image) is served by Ollama (pull a small VL model such as
# `moondream`). No Python package is required, but Pillow enables auto-downscaling
# of large photos (less RAM / latency):
#   pip install Pillow
# Pillow>=10.0
#

#   whisper.cpp (best for Termux): whisper-cli/whisper-cpp/main on PATH +
#     AGENT_WHISPER_CPP_MODEL pointing at a ggml model file
#   or: pip install openai-whisper
#   or: pip install faster-whisper
