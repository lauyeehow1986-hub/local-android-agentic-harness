# --- Optional, install only if you enable the heavy tools ---
# PDF reading (analyze_pdf) — pure-Python, ARM-friendly:
#   pip install pypdf
# pypdf>=4.0
#
# Scanned/image-only PDF OCR (analyze_pdf fallback) — a renderer + a vision model:
#   pip install pymupdf          # preferred, no system binary
#   # or: pip install pdf2image && pkg install poppler
# pymupdf>=1.24
#
# Browser tool (Playwright) — heavy on Termux; typically run on the LAN box:
#   pip install playwright && playwright install chromium
# playwright>=1.40
#
# Vision (analyze_image) is served by Ollama (pull a small VL model such as
# `moondream`). No Python package is required, but Pillow enables auto-downscaling
# of large photos (less RAM / latency):
#   pip install Pillow
# Pillow>=10.0
#
# transcribe (meeting speech-to-text) — install ONE Whisper backend:
#   whisper.cpp (best for Termux): whisper-cli/whisper-cpp/main on PATH +
#     AGENT_WHISPER_CPP_MODEL pointing at a ggml model file
#   or: pip install openai-whisper
#   or: pip install faster-whisper
# Non-WAV audio also needs ffmpeg (`pkg install ffmpeg`).
